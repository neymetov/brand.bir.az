## 3. Архитектурные развилки

| Вопрос | Суть |
| --- | --- |
| **Вложенность блоков** (№1) | Нужны ли колонки с блоками внутри секции. Сейчас Dynamic Zone плоская. Чем позже решится, тем дороже: переделка затронет и резолвер craft.js, и схему CMS |
| **Источник changelog** (№2) | Парсить `CHANGELOG.md` при сборке или принимать вебхуком. Раздел `/changelog` до ответа остаётся заглушкой |
| **Глубина вложенности папок** (№68) | Компонент Strapi не может содержать сам себя, поэтому в CMS заведено два уровня. Код рекурсивен. Нужно глубже — либо компонент на уровень, либо плоский список с полем `path` |
| **Статика страниц** (№108) | После переезда навигации в CMS страницы рендерятся на запрос. Нужна статика — потребуется ISR с ревалидацией по вебхуку |
| **Смена слага не переносит контент** (№107) | Старая страница остаётся в CMS недостижимой. Автопереноса нет: неясно, что делать при конфликте имён |
| **Снятие с публикации** (№104) | В редакторе только публикация. Отменить можно лишь в админке Strapi |

## 4. Ждёт дизайн-системы

| Вопрос | Детали |
| --- | --- |
| **Доступ к монорепо `@birds/ui`** (№6, №7, №10) | Playground читает исходники по заглушечному пути; иконки скачаны из Figma статикой вместо импорта из библиотеки |
| **Недостающие модули токенов** (№3) | `_misc`, часть шкал |
| **Брейкпоинты** (№9, №50) | Точные пиксели для Mobile / Tablet / Desktop+ не подтверждены. Границу 767px для мобильного режима выбрали мы |
| **Смысл `Spacing/margin`** (№4) | Значение скачет 16 → 189 → 341 между режимами; похоже на боковой отступ страницы, а не шаг шкалы |
| **Label и Caption не масштабируются** (№5) | Во всех четырёх режимах одинаковы — так задумано или упущение |
| **Расхождения токенов с макетами** (№8, №14, №71) | `--bb-text-tertiary`, фон строки m10, `Background/neutral/tertiary` (`#f4f4f5` в Figma против `#f1f5f9` у нас) |
| **Печатные цвета** (№23) | PMS и CMYK не описаны токенами — админ вводит их строкой |
| **Тема партнёрских брендов** (№102) | У них только плоские акцентные токены, полного каскада нет: интерфейс остаётся в теме экосистемы |
