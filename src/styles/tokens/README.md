# Токены — статус

Перенесено из `brand.bir.az/` (корень репозитория) без изменений содержимого,
только расположение. См. `docs/PROMPT.md` §5 и `docs/OPEN_QUESTIONS.md` №3.

## Реальные файлы (из `birds-tokens`, снимок 2026-07-09)

- `_colors.scss` — семантические `--bb-*` токены + миксин `-brand()` + 5
  активных блоков `[data-brand]` (ecosystem/retail/business/invest/private) +
  `--bb-partner-*` + приостановленный `[data-brand='hr-tech']` (**не
  трогать**, пауза на дизайне с 2026-07-09)
- `_primitives.scss` — примитивы (Tailwind-палитра + брендовые палитры +
  альфа + HR Tech draft-примитивы)

## Переведено из сырых данных (2026-08-05, при реализации дашборда)

- `_radius.scss` — из `radius-spacing-raw.json` → `radius`. Один режим, без
  media-запросов.
- `_spacing.scss` — из `radius-spacing-raw.json` → `spacing`. Значения
  режима **Desktop** (макет дашборда — 1440px). Точные пиксельные
  брейкпоинты для Mobile/Tablet/Desktop+ не подтверждены — см.
  `docs/OPEN_QUESTIONS.md` #7. Медиа-запросы оставлены закомментированными.
  `Spacing/margin` сознательно не включён в шкалу (#4).
- `_typography.scss` — из `typography-raw.json`. Тоже только режим Desktop,
  та же оговорка по брейкпоинтам.

Оба файла переведены по образцу `_colors.scss`/`_primitives.scss`
(`--bb-*` custom properties на `:root`, комментарий с источником Figma).

**Не проверено сборкой** — стилей, потребляющих эти токены с реальными
брейкпоинтами, ещё нет.

## Найденное расхождение (требует подтверждения у дизайнеров)

При переносе дашборда (см. `docs/PROMPT.md`, node `230:7792`) обнаружено:
Figma-переменная `text_and_icon/neutral/tertiary` в этом файле равна
`#9ca3af` (gray-400), а `--bb-text-tertiary` в `_colors.scss` (снимок
2026-07-02) — `gray-600` (`#4b5563`). Это НЕ то же самое значение. В коде
дашборда использован существующий `--bb-text-tertiary` (сохраняя семантику
роли, не хекс), но токен мог устареть — см. `docs/OPEN_QUESTIONS.md` #8.
